Why this is true / 为什么是这样

Reference first

The full-prefix path recomputes every position from scratch. It is the reference: slow, plain and unambiguous.

The cached path keeps K/V per layer and appends one slot per token. Both paths must agree at every position, under a tolerance fixed before the run: |a − r| ≤ 1e-5 + 1e-4·|r|.

Each fault is injected only into the cached path and is invisible at position 0. A correct lab catches every fault at position 1 or later.

Pages hold tokens, not bytes; the paging panel reports logical KV bytes, never process RSS or GPU memory.

先有参照物

全前缀路径每次都从头重算每一个位置。它是参照物：慢、直白、没有歧义。

缓存路径按层保存 K/V，每个 token 追加一个槽位。两条路径必须在每个位置一致，容差在运行之前就已固定：|a − r| ≤ 1e-5 + 1e-4·|r|。

每种故障只注入缓存路径，并且在位置 0 完全看不出来。正确的实验必须在位置 1 或更晚抓住它。

分页面板统计的是逻辑 KV 字节，不是进程 RSS 或显存。
